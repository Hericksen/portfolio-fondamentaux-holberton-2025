### ✨ Ajouté
- Système d'authentification JWT complet
- Interface utilisateur React avec design pixel-art
- Dashboard interactif avec statistiques XP/niveau
- Système de quêtes quotidiennes/hebdomadaires
- Système d'achievements avec déblocages
- Gestion d'avatar personnalisable
- Interface d'administration complète
- Explorateur de base de données intégré
- API REST complète avec documentation
- Tests unitaires et d'intégration
- Configuration Docker et docker-compose
- Scripts de démarrage automatique
- Documentation complète

- Base de données PostgreSQL avec Sequelize ORM
- Serveur Express.js avec middleware de sécurité
- Frontend Vite + React + TypeScript
- Styling avec Tailwind CSS + shadcn/ui
- Linting avec ESLint
- Variables d'environnement sécurisées

### 🏗️ Architecture
- Architecture REST API découplée
- Modèles de données relationnels
- Services de gamification modulaires
- Middleware d'authentification
- Gestion d'erreurs centralisée
- Structure de projet organisée

### 🎯 Fonctionnalités

- Statistiques de progression
