💡 Le Concept

PixelPump combine fitness et gamification pour créer une expérience d'entraînement unique et motivante.

  • 🎯 Système de Quêtes - Chaque exercice devient une mission
  • ⚡ Points d'Expérience - Progressez comme dans un RPG
  • 🏆 Achievements - Débloquez des badges et récompenses
  • 👤 Avatar Évolutif - Votre personnage grandit avec vous

🔧 Architecture Technique

Frontend

  • • React + TypeScript
  • • Vite (Build Tool)
  • • Tailwind CSS
  • • Radix UI Components

Backend

  • • Node.js + Express
  • • Sequelize ORM
  • • JWT Authentication
  • • API RESTful

Base de Données

  • • PostgreSQL
  • • Migrations automatiques
  • • Scripts d'initialisation
  • • Données de test

DevOps

  • • Docker + Docker Compose
  • • Scripts de déploiement
  • • Configuration CI/CD
  • • Monitoring intégré
